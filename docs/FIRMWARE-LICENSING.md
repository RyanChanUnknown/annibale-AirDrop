## 发布方式

公开包不含固件；用户通过获取工具从三星官方服务器下载并在本地还原，或自行提供有权使用的匹配文件。工具、位置索引和 SHA-256 不嵌入固件字节。安装器只接受固定哈希，并优先复用已安装模块的匹配文件。

这种方式减少本仓库直接再分发固件的风险，但不保证任何地区的提取、跨设备使用都当然获准；用户仍需遵守来源条款。如果将来希望直接附带 bin，应先取得覆盖公开下载、目标平台、修改与通知要求的授权，并保留证明。

发布前同时检查 Git 历史、标签、Release 附件及嵌套归档。只添加 `.gitignore` 不能删除历史中已有的文件。K90 当前公开历史和发布附件没有包含此固件。
